# T00.05 — OpenAPI: internal provisioning and operations APIs (`openapi/`)

## Goal

Author the OpenAPI documents for the 11 internal operations (C.97–C.107):
the desired-state provisioning contract toward Repo 3 and the typed
restriction/action contract toward Repo 4.

## Context

These endpoints are forbidden to the browser (Repo 2 boundary) and carry the
platform's two most sensitive interfaces: Repo 1 §29 desired-state /
observed-generation exchange (mirrored by Repo 3 §48–§51) and the Repo 4
request-only restriction path (OPS-BND-001, Repo 4 Appendix AI delta AI-01).
Divergence between the Repo 1 and Repo 3 descriptions of the same exchange
must surface here, not at integration time.

## Steps

- ☐ Author C.97–C.107 with full request/response schemas, in a document
  clearly separated from the public surface
- ☐ Reconcile the provisioning shapes against Repo 3 §48–§51 field by field;
  any mismatch is an ADR, not a silent fix
- ☐ Reconcile the restriction/action shapes against Repo 4 Appendix AI
  (AI-01..AI-03)
- ☐ Mark generation/idempotency semantics per Repo 1 §29/§34 annotations

## Acceptance criteria

- Operation count reconciles to 11 (C.97–C.107)
- Field-level reconciliation notes exist for both sibling specs, each
  discrepancy resolved or raised as an ADR
- Lint passes with the harness ruleset

## Evidence

Lint output; both reconciliation notes filed with Gate 0 records.
