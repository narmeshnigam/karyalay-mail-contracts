# T00.12 — Tag `v0.1.0` and close Gate 0

## Goal

Cut the first immutable contract release and record the evidence that closes
Gate 0 — unblocking Phase 0 in all four consumer repositories.

## Context

Consumers pin tags, never branches. The tag is the single event the entire
programme's dependency graph hangs on. ADR-KEM-002/003 decisions (T00.10,
T00.11) are strongly preferred before tagging but are not structural
blockers to the tag itself — they gate specific downstream tasks, not the
contract artifacts.

## Steps

- ☑ Final harness run green on the complete artifact set
- ☑ Write the release inventory (every artifact + its source appendix) into
  the annotated tag message / release notes
- ☑ Tag `v0.1.0`; verify immutability convention is documented (a tag is
  never moved; fixes ship as `v0.1.1+` per Master §0.4)
- ☐ Each consumer repo pins the tag per `CONSUMING.md` and records a green
  validation run (four evidence entries)
- ☐ Update each consumer repo's Phase 0 blocker rows from
  "karyalay-mail-contracts v0.1.0 (Gate 0 tag)" to unblocked
- ☐ Record Gate 0 closure in the decision register

## Acceptance criteria

- Tag exists; four consumer validation runs recorded; register updated

## Evidence

Annotated tag, release inventory, four consumer CI records.

## Progress — 2026-08-18

**Done here.** Harness green (21 checks, 0 failures) and Redocly clean.
`v0.1.0` tagged and annotated with the release inventory. The immutability
convention is documented in `CONSUMING.md` and enforced by the
`tag-is-immutable` CI job, which rejects a lightweight tag.

**Not done, and not doable from this repository.** Four steps require the
consumer repositories:

- Each consumer pins the tag per `CONSUMING.md` and records a green validation
  run — four evidence entries.
- Each consumer's Phase 0 blocker rows change from
  "karyalay-mail-contracts v0.1.0 (Gate 0 tag)" to unblocked.
- The decision register records Gate 0 closure once those four runs exist.

This is the split ADR-KEM-001 always described and BUILD-ORDER §4 restates:
**the tag unblocks Wave 1; the gate closes during it.** This task stays
in-progress until the four consumer runs are recorded, and it is the only Gate 0
task that does.
